## Projetos

### [Detector e reescritor de texto gerado por IA](https://github.com/fonsecaalari-gif/detector-texto-ia)

Estudo com 8.737 textos escritos por pessoas, pelo ChatGPT e pelo Claude: quais variáveis de estilo diferenciam humano e IA, quão bem os detectores generalizam e quanto uma reescrita consegue enganá-los.

- 51 variáveis medidas por texto, 47 com diferença significativa (com correção para comparações múltiplas)
- Detectores com ROC-AUC de até 0,998, mas que marcam como IA 95% das redações humanas quando o tipo de texto muda
- Reescritor guiado pelas variáveis e teste de robustez, com [app online](https://detector-texto-ia-larissa.streamlit.app)

Python, spaCy, scikit-learn, SciPy, Streamlit, pytest

### [Previsão de churn de clientes](https://github.com/fonsecaalari-gif/previsao-churn-clientes)

Modelo que indica quais clientes de uma operadora de telecom devem receber uma oferta de retenção. O limiar de decisão foi escolhido pelo lucro da campanha.

- Lucro 31% maior que o do mesmo modelo com limiar padrão e quase 4 vezes o de abordar clientes ao acaso
- Encontra 84,5% dos clientes que iriam cancelar
- 18 testes automatizados, CI com GitHub Actions e [app online](https://previsao-churn-larissa.streamlit.app) em Streamlit

Python, pandas, scikit-learn, XGBoost, Streamlit, pytest
